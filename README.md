# 家族カレンダー（デモ版）

家族それぞれが入っているコミュニティ（部活・習い事・PTA/自治会・仕事・家族の行事）の予定を、**1つのカレンダーにまとめて**見られる、家族向けのウェブアプリです。

> アプリ名は「家族カレンダー」です。これは**デモ版**で、登場する家族（たかし・みさき・あおい・りく）と予定は、すべて架空です。

## できること
- 月・タイムライン（人別）・一覧の3つの表示と、家族の色分け
- 予定の追加・編集、毎年の予定（誕生日など）
- **サンプル予定の取り込み体験**：右上の「取込」→「サンプル予定の取り込み」で、部活・習い事・PTA/自治会の予定をボタン1つで取り込む
- TimeTree・.ics ファイル・バックアップの取り込み（この端末の中だけで動く）
- 暗証番号の画面（デモの番号は画面に書いてあります）

## デモ版で外してあるもの（本物の版にはある機能）
- 家族の端末どうしの予定の同期（データベース）
- Google・Apple・Outlook カレンダーの自動同期
- スマホへの予定の通知
- 家族を招待する QR コード

予定は、この端末のブラウザの中だけに保存されます（外部には送りません）。

## 動かし方
```
npm install
npm run dev      # 手元で動かす（http://localhost:5173/）
npm run build    # 公開用のファイルを dist/ に作る
```
